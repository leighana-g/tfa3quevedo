# TFA3 – User and Customer Management

By Franz Matthew Quevedo

A CodeIgniter 4 web application for managing users and customers.

## Live Website
https://tfa3quevedo.infinityfree.io/

## Features
- View, add, edit, and delete users
- View, add, edit, and delete customers
- Upload user avatars

## Technologies
- PHP and CodeIgniter 4
- MySQL
- HTML, CSS, and JavaScript
- InfinityFree hosting

## Configuration
Database credentials are stored in a local .env file excluded from Git.
Install project dependencies with Composer before running locally.
